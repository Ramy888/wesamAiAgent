# Finding a seller, and running the session

Everything the judges score — hours saved, money saved, revenue — comes from one or two real COD
sellers. This is the pack for getting one and running a 45-minute session that produces the slide
numbers, the demo material, and the answer to bug #8.

Target: **two sellers**, one Egyptian, ideally one Gulf. One is enough if time is short.

## 1. Where to find them

In rough order of how fast they reply:

1. People you already know who sell on Facebook or TikTok — one warm introduction beats twenty cold
   messages.
2. Egyptian COD seller groups on Facebook: search «تجار أونلاين», «كوميرس مصر», «دروب شيبنج مصر»,
   «تجارة الكترونية مصر».
3. Sellers whose ads you see on your own feed. Message the page directly.
4. Courier communities: Bosta, Mylerz and Aramex Egypt have active seller groups.
5. Salla and Zid merchant communities, for the Gulf.

## 2. The outreach message (Arabic, ready to send)

> مساء الخير 👋 أنا ببني مساعد ذكاء اصطناعي بيحسب للتاجر مكسبه الحقيقي في الأوردر بعد الشحن والمرتجع
> والإعلانات، وبيقوله الحملة دي تكمّل ولا توقف. محتاج تاجر واحد يجرّبه على منتج حقيقي ويقوللي بصراحة
> رأيه. الجلسة ٤٥ دقيقة أونلاين، مجانية تماماً، وأرقامك تفضل سرية ومش هتظهر باسمك في أي حتة. اللي
> هتاخده: تسعيرة صح لمنتجك، أقصى تكلفة ليد تقدر تدفعها، ومراجعة لحملة شغالة عندك دلوقتي. ينفع نتكلم؟

Keep it to that. No links in the first message: links get filtered in most groups.

**If they ask "what's in it for me":** a correct price for one product, the ceiling on what they can
pay per lead, and a verdict on a live campaign. That's real work, done free.

**If they hesitate about their numbers:** they can use round figures. The point is the decision, not
their accounting.

## 3. Before the session

- Send the consent line and get a yes in writing: «موافق إني أستخدم أرقامك بشكل مجهول (من غير اسمك
  ولا اسم صفحتك) في عرض تقديمي وفيديو للمسابقة؟»
- Ask them to have open: their product cost, their courier's price list, and Ads Manager for one
  live campaign.
- Check that Afandina answers a test question, so the session doesn't start with a broken tool.
- Have a stopwatch. The timings are the impact slide.

## 4. The session (45 minutes)

**Part 1 — how they do it today (15 min). Do this first, before they see Afandina.**

Ask them to price a product **the way they normally would**, out loud, while you time it. Don't
help, don't hint. Record:

| Question                                                  | Their answer |
| --------------------------------------------------------- | ------------ |
| How do you decide the price of a new product?             |              |
| **Minutes taken** (timed, not estimated)                  |              |
| How many new products a week?                             |              |
| How do you decide to stop an ad? After how long?          |              |
| **Minutes per campaign review** (timed)                   |              |
| How many campaigns a week?                                |              |
| Do you count returns and unconfirmed orders in the price? |              |
| Last time an ad lost money — how long before you noticed? |              |
| Have you ever launched an offer that lost money?          |              |

That last pair is where the "money saved" number comes from.

**Part 2 — the same product through Afandina (20 min).**

Collect these, which are exactly what the tool needs:

| Input                                              | Value |
| -------------------------------------------------- | ----- |
| Product cost, and customs per unit                 |       |
| Delivery fee, return shipping fee                  |       |
| Packaging, fulfilment                              |       |
| Call centre and SMS per lead                       |       |
| Platform %, gateway % and fixed, VAT %, marketer % |       |
| Confirmation rate %, delivery rate %               |       |
| Cost per lead                                      |       |
| Their current selling price                        |       |
| Target margin %                                    |       |
| Live campaign: spend, leads, confirmed, delivered  |       |

Then, while they watch: price the product, check the live campaign, check one offer they're
considering. **Time it.** Screen-record the whole thing with their permission; this is also demo
footage.

**Part 3 — their verdict (10 min).**

- Is the price Afandina suggested sensible for their market? If not, why not?
- Was the campaign verdict right, by their judgement?
- Would they change anything they do tomorrow because of this?
- What did it miss?
- **Bug #8:** ask directly — "packaging and fulfilment: do you pay those on every order you ship, or
  only on the ones that get delivered and paid?" Ask the same about the fixed payment-gateway fee.
  Their answer decides the bug (`CLAUDE.md` §6, item 8).

Part 3 is also the expert validation that has been outstanding: a practitioner judging real answers.

## 5. After the session

- Fill in the worksheet in `docs/impact-slides.md` the same day.
- Money saved: if a campaign came out as PAUSE, agree with the seller what it was losing per day and
  how long they'd have left it running. Write down both numbers and who said them.
- Revenue: only claim it after a week of real orders on a changed price or a new bundle.
- Ask for one sentence to quote, in their own words, and permission to use it anonymously.
- Add their week to the weekly workflow and let it run once, which closes item 6.

## 6. Rules

- **Never invent a number.** A blank on a slide is survivable; an invented figure is not.
- Anonymize by default: "a Cairo seller in home appliances", never their page name.
- Don't show them formulas or internals, per the standing rule.
- If their numbers say Afandina is wrong, that is the most valuable outcome of the whole project. Write
  it down exactly and fix it.
