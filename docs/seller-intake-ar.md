# جلسة التاجر — الدليل الكامل (٤٥ دقيقة)

النسخة العربية من `docs/seller-intake.md`. اللهجة مصرية؛ لو التاجر خليجي غيّر «إزاي» لـ «كيف» و«عايز»
لـ «أبغى»، والباقي زي ما هو.

**الهدف:** أرقام حقيقية من تاجر حقيقي. من غيرها مفيش «وقت اتوفّر» ولا «فلوس اتحفظت» في العرض التقديمي
— والأرقام المتخيلة تحرق المشاركة كلها.

---

## ١. رسالة التواصل (ابعتها زي ما هي)

> مساء الخير 👋 أنا ببني مساعد ذكاء اصطناعي بيحسب للتاجر مكسبه الحقيقي في الأوردر بعد الشحن والمرتجع
> والإعلانات، وبيقوله الحملة دي تكمّل ولا توقف. محتاج تاجر واحد يجرّبه على منتج حقيقي ويقوللي بصراحة
> رأيه. الجلسة ٤٥ دقيقة أونلاين، مجانية تماماً، وأرقامك تفضل سرية ومش هتظهر باسمك في أي حتة. اللي
> هتاخده: تسعيرة صح لمنتجك، أقصى تكلفة ليد تقدر تدفعها، ومراجعة لحملة شغالة عندك دلوقتي. ينفع نتكلم؟

**لو سأل «وأنا هستفيد إيه؟»** — سعر صح لمنتج واحد، وسقف تكلفة الليد، وحكم على حملة شغالة. شغل حقيقي،
ببلاش.

**لو اتكسف من أرقامه** — «الأرقام التقريبية تكفي، إحنا عايزين القرار مش المحاسبة».

---

## ٢. قبل الجلسة

- **الموافقة، مكتوبة:** «موافق إني أستخدم أرقامك بشكل مجهول — من غير اسمك ولا اسم صفحتك — في عرض
  تقديمي وفيديو للمسابقة؟»
- اطلب منه يفتح: فاتورة المنتج، أسعار شركة الشحن، وحملة واحدة شغالة في مدير الإعلانات.
- جرّب افندينا بسؤال واحد قبل ما تبدأ، عشان الجلسة ما تبدأش بعطل.
- حضّر ساعة إيقاف. التوقيت ده هو رقم «الوقت اللي اتوفّر».

---

## ٣. الجزء الأول — إزاي بيشتغل دلوقتي (١٥ دقيقة)

**مهم: ده قبل ما يشوف افندينا خالص.** سيبه يسعّر بطريقته وهو بيتكلم بصوت عالي، وإنت بتحسب الوقت. ما
تساعدوش وما تلمّحش.

| السؤال                                               | إجابته |
| ---------------------------------------------------- | ------ |
| بتحدّد سعر المنتج الجديد إزاي؟                        |        |
| **الوقت الفعلي بالدقايق** (محسوب، مش تقديري)         |        |
| كام منتج جديد في الأسبوع؟                            |        |
| بتقرّر توقف الإعلان إزاي؟ وبعد قد إيه؟                |        |
| **وقت مراجعة الحملة الواحدة** (محسوب)                |        |
| كام حملة في الأسبوع؟                                 |        |
| بتحسب المرتجعات والأوردرات اللي ما اتأكدتش في السعر؟ |        |
| آخر مرة إعلان خسّرك — عرفت بعد قد إيه؟                |        |
| نزّلت عرض قبل كده وطلع خسران؟                         |        |

آخر سؤالين هما مصدر رقم «الفلوس اللي اتحفظت»، فخد وقتك فيهم.

---

## ٤. الجزء الثاني — نفس المنتج على افندينا (٢٠ دقيقة)

اجمع الأرقام دي — بالظبط اللي الأداة محتاجاه:

| المدخل                                                                  | القيمة |
| ----------------------------------------------------------------------- | ------ |
| تكلفة المنتج + الجمارك للوحدة                                           |        |
| رسوم التوصيل ورسوم المرتجع                                              |        |
| التغليف والتجهيز                                                        |        |
| الكول سنتر و SMS لكل ليد                                                |        |
| عمولة المنصة %، بوابة الدفع % + الثابت، الضريبة %، عمولة المسوّق %       |        |
| **عمولة تحصيل الكاش من شركة الشحن %** (كتير بياخدوا ١–٢٫٥٪)             |        |
| نسبة التأكيد % ونسبة التسليم %                                          |        |
| تكلفة الليد                                                             |        |
| سعر البيع الحالي                                                        |        |
| الهامش المستهدف %                                                       |        |
| الحملة الشغالة: الصرف، الليدز، المؤكد، المستلم، **واللي لسه في الطريق** |        |

بعدين، وهو قاعد معاك: سعّر المنتج، راجع الحملة، جرّب عرض واحد بيفكر فيه. **واحسب الوقت.** سجّل الشاشة
بإذنه — ده كمان لقطات للفيديو.

**انتبه لحاجتين وإنت بتسأل:**

- «الليد» يعني إيه عنده بالظبط؟ رسالة، رقم تليفون، ولا أوردر كامل البيانات؟
- سعر المورّد شامل الجمارك أصلاً ولا لأ؟ عشان ما نحسبهاش مرتين.

---

## ٥. الجزء الثالث — رأيه هو (١٠ دقايق)

- السعر اللي طلع منطقي لسوقك؟ لو لأ، ليه؟
- حكم الحملة صح من وجهة نظرك؟
- هتغيّر حاجة بكرة بسبب اللي شوفته؟
- الأداة ناقصها إيه؟

**وسؤال الـ Bug #8 بالنص:**

> «التغليف والتجهيز — بتدفعهم على كل أوردر بيتشحن، ولا بس اللي بيتسلّم ويتدفع؟»
>
> «والرسوم الثابتة لبوابة الدفع؟»

إجابته هي اللي هتحسم الحسبة دي عندنا، فاكتبها بالنص كما قالها.

الجزء ده كمان هو «مراجعة الخبير» اللي لسه ناقصانا: تاجر شايف نتايج حقيقية ويقول رأيه فيها.

---

## ٦. بعد الجلسة، في نفس اليوم

- املا الورقة اللي في `docs/impact-slides.md`.
- **الفلوس:** لو طلعت حملة «وقّفها» — اتفق معاه: كانت بتخسر كام في اليوم؟ وكان هيسيبها كام يوم كمان؟
  اكتب الرقمين ومين قالهم.
- **الإيراد:** ما تكتبش رقم غير بعد أسبوع أوردرات حقيقية على السعر أو العرض الجديد.
- اطلب جملة واحدة بصوته للاقتباس، وموافقة إننا نستخدمها من غير اسمه.
- شغّل المتابعة الأسبوعية على أرقامه مرة واحدة.

---

## ٧. قواعد ثابتة

- **ما تخترعش رقم.** خانة فاضية في العرض أهون بكتير من رقم متخيل.
- الاسم مجهول افتراضيًا: «تاجر في القاهرة بيبيع أجهزة منزلية»، مش اسم صفحته.
- ما تشرحش المعادلات ولا طريقة الحساب.
- **لو أرقامه أثبتت إن افندينا غلط — ده أهم ناتج ممكن نخرج بيه.** اكتبها بالظبط وصلّحها.
